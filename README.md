# Zero Trust Security in Permissioned Blockchain (Hyperledger Fabric)

Capstone project analyzing how Zero Trust principles can strengthen security in permissioned blockchain environments, with a focus on Hyperledger Fabric.

## Highlights
- Analyzed Hyperledger Fabric security mechanisms (MSP, PKI, RBAC, ACLs, channels, private data collections)
- Mapped Zero Trust principles (never trust, always verify; least privilege; continuous verification) to Fabric architecture
- Identified risks: insider threats, over-privileged access, misconfigurations, and lateral movement
- Developed a Zero Trust–aligned security framework with actionable recommendations for enterprise deployments
- Considered applicability in regulated industries (banking, finance, supply chain) and compliance (PCI-DSS, SOX, HIPAA)
